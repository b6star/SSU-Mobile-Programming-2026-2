# 07주차 실습 — 이벤트 처리 다루기

## 실습

ImageButton, CheckBox, RadioButton, ToggleButton, Switch의 이벤트를 처리하여 그림 퀴즈와 조명 제어 화면을 구현한다.

## 구현 내용

| 모듈 | 예제 | 구현 내용 |
| --- | --- | --- |
| [mp0501](./mp0501/) | 5-1 | ImageButton 클릭 시 선택한 그림을 표시하고 정답 여부를 Toast로 출력 |
| [mp0502](./mp0502/) | 5-2 | CheckBox로 소방관 용품을 선택하고 선택한 물건의 이름 출력, 정답 확인 및 재시작 |
| [mp0503](./mp0503/) | 5-3 | RadioButton으로 고양이 그림자를 선택하고 정답 여부를 Toast로 출력 |
| [mp0504](./mp0504/) | 5-4 | ToggleButton 상태에 따라 벽면 버튼, 배경 및 조명 이미지 변경 |
| [mp0505](./mp0505/) | 5-5 | Switch로 고양이 표시 여부와 조명 상태를 각각 제어 |
