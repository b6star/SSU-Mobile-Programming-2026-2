# 06주차 실습 — 레이아웃 다루기

## 실습

ConstraintLayout, LinearLayout, FrameLayout, TableLayout을 사용해 화면을 구성하고 입력 및 클릭 이벤트를 처리한다.

## 구현 내용

| 모듈 | 예제 | 구현 내용 |
| --- | --- | --- |
| [mp0601](./mp0601/) | 6-1 (원본 4-1) | ConstraintLayout으로 두 주사위의 합을 입력받아 정답 확인 |
| [mp0602](./mp0602/) | 6-2 (원본 4-2) | LinearLayout으로 고양이 수를 비교하고 부등호 선택 |
| [mp0603](./mp0603/) | 6-3 (원본 4-3) | FrameLayout으로 드레스, 왕관, 목걸이를 겹쳐 캐릭터 꾸미기 |
| [mp0604](./mp0604/) | 6-4 (원본 4-4) | TableLayout으로 거북이와 물고기 수를 입력받아 정답 확인 |
