# 05주차 실습 — 기본 위젯 다루기

## 실습

TextView, Button, EditText, ImageView, ImageButton의 속성과 이벤트 처리를 실습한다.

## 구현 내용

| 모듈 | 예제 | 구현 내용 |

| [mp0301](./mp0301/) | 3-1 | XML에서 Hello World의 색상, 글꼴, 크기 설정 |
| [mp0302](./mp0302/) | 3-2 | Kotlin 메서드로 TextView의 텍스트와 속성 설정 |
| [mp0303](./mp0303/) | 3-3 | 버튼 클릭 시 두 수의 합을 Toast로 출력 |
| [mp0304](./mp0304/) | 3-4 | 입력 형식별 EditText 구성 및 입력 결과 출력 |
| [mp0305](./mp0305/) | 3-5 | 다음보기 버튼으로 고양이 이미지를 순환 표시 |
| [mp0306](./mp0306/) | 3-6 | 이미지 순환 및 ImageButton의 상태별 이미지 변경 |
